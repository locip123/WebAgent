# 系统初始根路径由执行器独占维护

路径树保留为 WebRetriever 的探索规划机制，但系统初始根路径 `1` 只作为执行器拥有的任务锚点，固定进展为“准备分析任务起始页面寻找所有可到达任务目的地或正确页面的路线”；模型在首轮路径审查中至少必须以一个 `add` 创建具体探索路径，其他操作仍由通用路径协议校验。缺少 `add` 的决策不执行浏览器动作，而在同一步获得修复反馈；这是首轮审查唯一新增的拒绝条件。追加操作按顺序应用，因此同一决策可选择首个新建子路径并立即执行其浏览器动作；不能更新或引用未由当前树或本轮 `add` 产生的路径。相较于移除路径树或允许模型编辑根路径，这能保留可审计的探索计划，同时消除根路径被错误更新及未创建路径被更新的失败模式。
