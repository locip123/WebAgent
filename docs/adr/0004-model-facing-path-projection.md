# 模型可见路径投影与路径变更解耦

持久化 `path.json` 保持既有格式，但发送给模型的路径树使用投影：系统根路径仅呈现为带标识、子路径、`kind: "system_anchor"` 和 `immutable: true` 的不可变锚点，不暴露普通路线字段。顶层 `progress` 由不兼容的 `decision_summary` 取代，记录本轮观察与行动意图，不再自动写入路径树；真实路径变更仅来自显式 `path_json_action`，其中 `update.progress` 记录已验证路线进展，或在成功/失败状态转换时记录相应证据。根节点更新仍拒绝整份决策；五次无新验证事实仅触发停滞恢复提示而不隐式修改路径。该边界以略高的显式操作成本换取可审计状态、清晰的模型语义和对根节点错误更新的结构性抑制。
