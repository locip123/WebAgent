# WebRetriever

WebRetriever 在受控浏览器中检索网页与官方文档，并保留可复核的任务证据。

## Language

### 任务执行

**任务收尾窗口**：
浏览任务主体终止后，为有界地保存已取得的证据并释放运行时资源保留的 60 秒期间。主体任务截止与收尾窗口分别计时，后者不能改变已确定的终态；单次运行的绝对上限是两者之和。
_Avoid_: 无限清理、任务结束后继续等待

**收尾取消**：
任务收尾窗口开始时，对仍未完成的浏览器运行时任务立即发出的终止处理；最终结果只纳入已完成或已持久化的证据。
_Avoid_: 被动清空后台任务、继续取证

**收尾诊断**：
最终任务产物中对收尾窗口的完成状态、耗时和残留运行时任务所作的独立记录；它补充而不覆盖主体任务终态。
_Avoid_: 收尾失败状态、运行时失败

### 模型可用性

**模型调用序列**：
为取得一次 WebRetriever 模型响应而对同一请求进行的一组连续尝试；首次请求计入尝试次数，序列最多包含 5 次尝试。
_Avoid_: 5 次重试、6 次调用

**模型等待耗时表**：
一次浏览任务结束后保存的逐步 Agent 决策模型调用耗时记录；每项包含该步全部尝试的等待时间，成功、失败和超时均计入。图表分类或数据分析的内部调用采用相同重连策略，但不写入此表。
_Avoid_: 总模型用时、内部模型调用日志

### 探索策略

**策略复盘**：
Agent 对已尝试与尚可尝试的取证路径所作的四部分、持久化探索状态更新；它审阅自上次复盘以来的全部完成决策，并在确认进入新页面时立即发生，或在同页累计 20 个完成决策时兜底发生。
_Avoid_: 15 步检查点、普通记忆

**页面进入**：
一次已执行浏览器动作后的下一轮观察中，去除 `#fragment` 后的有效页面 URL 与前一轮不同；重定向以落地页计，下载占位页 `:` 不计，起始页首次加载完成计入。
_Avoid_: 锚点跳转、下载标签页

**完成决策**：
已通过结构化校验并结束处理的一次 AgentDecision；本地阻止和浏览器动作失败包含在内，模型超时或无效输出不包含在内。
_Avoid_: 模型调用、浏览器动作

### 风控验证

**风控缓解**：
同一 CDP 端点的对照实验中，实验浏览器客户端的可见验证轮次严格少于基线，且成功任务数不低于基线。
_Avoid_: 验证通过率提高、偶然成功

**最小风控对照**：
在一个 CDP 端点上按固定顺序各运行一次基线与实验浏览器客户端的风控缓解验证。
_Avoid_: AB/BA 矩阵、多端点重复实验

### 图表取证

**可分析数据工件**：
保留一方来源与筛选上下文、且已归一化为结构化数据集的证据，可用于受限的本地数据分析。
_Avoid_: ready data dir、可用 CSV 文件夹

**可分析图表工件**：
来源为图表流量的可分析数据工件。
_Avoid_: ready data dir、可用 CSV 文件夹

**可分析工件提示**：
可分析数据工件首次就绪后，在下一次 Agent 决策中一次性提供的简要可用性提示；它建议而不代替 Agent 发起数据分析。
_Avoid_: 自动分析、持续提醒、分析结果

**受限数据分析**：
Agent 对本任务内、manifest 已验证的可分析数据工件进行的只读本地分析；图表与下载数据使用同一分析入口。
_Avoid_: 图表专用分析、任意本地分析、联网分析

**分析证据引用**：
受限数据分析返回的可复核定位信息，包含原始 URL、工件身份、数据位置及所用字段或筛选条件；没有此信息的分析结论不能支撑任务完成。
_Avoid_: 分析摘要、裸结论、模型记忆

**下载超时工件**：
在下载期限内未到达就绪或失败状态的阻塞下载工件；它取消剩余下载或解析、解除下载完成观察但不结束浏览任务，并要求 Agent 转向其他一方取证路径。
_Avoid_: 任务超时、下载失败、任务结束

**下载失败工件**：
下载或归一化出错的阻塞下载工件；原件与来源诊断仍被保留，但它不可用于受限数据分析，也不会延迟后续观察。
_Avoid_: 下载超时工件、丢弃的下载、可分析数据工件

**原始图表工件**：
保留了目标图表的一方原始响应、但尚未归一化出结构化数据集的图表证据；它仍是可复核证据，不等同于没有数据，且不触发原始载荷解码。
_Avoid_: saved_raw_only、空图表数据

**未匹配图表流量**：
当前扫描未选出任何与目标图表有关的一方数据请求的结果；它不表示页面可见图表或表格不存在。
_Avoid_: 空结果、图表不存在

**图表视觉回退**：
在没有可分析图表工件时，直接从当前页面的图表、图片表格、DOM、提示框或已观察到的一方导出中取得证据的取证方式。
_Avoid_: 原始载荷解码、重复扫描

**下载归档**：
Agent 在浏览任务中下载的 `.zip` 文件；首版不包括 TAR、RAR、7z 或其他压缩格式。
_Avoid_: 压缩包、归档文件

**解压产物**：
从下载归档中释放并保留的文件或目录；每个文件都作为可独立检索和引用的证据向 Agent 暴露，并保留其来源下载归档。解压产物不会替代作为原始证据的下载归档。
_Avoid_: 解压文件

**下载占位页**：
浏览器为新标签页下载创建的、URL 为 `":"` 且不包含可检索内容的临时页面。下载占位页本身不是证据；其产生的下载文件是独立证据。
_Avoid_: PDF 页面、下载标签页

**下载完成观察**：
在将下一份浏览器观察交给 Agent 前，必须等待当前任务已触发的全部下载工件到达完成、失败或下载期限终止状态的观察方式。
_Avoid_: 后台下载、非阻塞下载、下载中观察

**阻塞下载工件**：
会参与下载完成观察的一方证据，限于 Agent 触发的浏览器下载以及状态为 2xx 的顶层导航非 HTML 文档响应；图片、字体、脚本和普通 XHR 不属于此类。
_Avoid_: 页面资源、全部网络响应、XHR 下载

**页面首次观察**：
一次导航后首次交给 Agent 的浏览器状态；HTML 页面在导航开始 10 秒后即可形成，而已成为阻塞下载工件的导航必须在其终态后形成。
_Avoid_: 固定等待、下载中观察、页面加载完成

**导航超时观察**：
HTML 导航超过 120 秒仍未完成时保留当前已渲染内容、停止剩余加载后交给 Agent 的浏览器状态；它不结束浏览任务。
_Avoid_: 任务超时、空白重试、导航失败即结束

**截图恢复页面**：
当前页面无法完成截图时，用于继续观察的存活运行时页面；优先原页面的 opener，否则选最近的存活安全页面。它不会重新导航或创建页面。
_Avoid_: 截图重试、刷新页面

### 文档取证

**下载观察**：
对当前任务已产生的下载文件所作的可复核描述，包含文件身份、来源、状态、大小、提取状态及有界的文件内容预览。
_Avoid_: 下载占位页、后台下载

**任务证据索引**：
仅由当前任务已经观察到的页面文本和下载证据构成的可检索集合；索引结果必须保留其原始来源和字段位置。
_Avoid_: 全局索引、外部资料索引

**字面编号匹配**：
文档检索按原文字符匹配编号；`12`、`012` 和 `0012` 是不同的查询词，不自动视为同一编号。
_Avoid_: 编号归一化、数字等价匹配
