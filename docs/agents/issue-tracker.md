# Issue tracker: GitHub

Issues and specifications live in `locip123/WebAgent` GitHub Issues.
Use the `gh` CLI and explicitly target `locip123/WebAgent`.

- Publish a specification or ticket by creating a GitHub issue.
- Read full issue bodies and comments before acting.
- Apply or remove labels with GitHub issue operations.
- Close issues only when the invoking workflow explicitly requires it.
- Pull requests are not a triage request surface.
- Use GitHub native blocking relationships when available; otherwise
  record blocking issue references in the issue body.
